# Aida（アイーダ）

Yet another split keyboard, based on SandyLP.

Aida is a 40% split keyboard with symmetrical row staggered layout and key height optimization.

---

Aidaは左右対称ロースタッガード配列の40%分割型キーボードで、スイッチの配置を立体的にして高さ方向への最適化をおこなっています。

前機種の[SandyLP](https://github.com/jpskenn/SandyLP)を元に、分割型へ派生しました。

## 開発経緯

〓「キーボード遍歴の振り返り」というところから、分割型への期待、カラムスタガのつらさなども入れて説明し、現在Aidaに到達しているということを言いたい。
